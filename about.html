About StudentHub

A modern, unified campus management system built for CHARUSAT students and faculty.

Our Mission

StudentHub is created under the Web Development Frameworks (ITUE203) curriculum at the Faculty of Technology and Engineering (FTE), CHARUSAT. The portal simplifies academic administration by providing intuitive tools for attendance tracking, course registration, exam marks evaluation, fee processing, and campus event engagement.

Core Capabilities

  • Semantic & Accessible: Built with HTML5 semantic elements (header, nav, main, article, footer) adhering to WCAG accessibility guidelines.
  • Responsive Design: Clean responsive CSS Grid and Flexbox layouts suitable for mobile phones, tablets, and desktop computers.
  • Dynamic Frontend Interactivity: JavaScript-powered interactive FAQs, modal popups, carousels, and persistent dark/light mode.
  • Robust Backend Services: PHP session handling, MySQL relational database management, prepared statements, and bcrypt password security.
  • Role-Based Access Control: Strict separation of administrator capabilities and student portal views.
